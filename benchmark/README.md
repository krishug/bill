# 人工基准集

1. 每张基准图片/PDF页由人工逐项核对票面：发票号码、金额、税额、价税合计、销售方名称。票面确实未印字段时留空；只有票面明确免税/不征税并显示零税额时才标注 `0.00`。
2. 在 `ground_truth.template.csv` 的副本中填写人工确认值，`filename` 和 `page_number` 必须与 Excel“发票明细”中的原始文件名和 PDF页码一致；图片的页码留空。
3. 运行 README 中的 `benchmark/evaluate_accuracy.py` 命令查看每个字段的严格精确匹配率。金额字段按两位小数比较；公司名称和号码按文本精确比较。
4. 将基准结果按清晰普通票、模糊/倾斜、缺失字段、金额校验差异、红字/负数、重复、无效图片、多金额干扰等类别分组记录。重复图片应分别保留为两条样本。

该目录只提供空模板，不包含任何发票图片或用户发票字段。请勿把模型置信度当作正确率；正确率只由人工标注结果计算。
